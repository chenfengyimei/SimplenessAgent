# SimplenessAgent 数据模型与接口契约

## 1. 设计目的

本文件定义核心领域对象和跨模块契约的初版形态。字段会在实现阶段转化为 Go 类型、JSON Schema 和 SQLite Migration。

规则：

- 所有持久化协议带 `version`。
- ID 全局唯一且稳定，不使用可变名称作为关联键。
- 时间统一保存 UTC，UI 按本地时区展示。
- 大正文通过 Artifact 引用，不无限写入 JSON 字段。
- 枚举新增保持向后兼容，删除或改义需要主版本升级。

## 20. UI Event Stream

事件包含：

- `sequence`
- `event_type`
- `task_id`
- `timestamp`
- `summary`
- `payload`

前端维护最后 Sequence。断线后使用 `afterSequence` 补拉，不能假定流式连接永久稳定。

## 21. 数据库约束

- Foreign Key 开启。
- WAL 模式。
- 状态更新与 Event Append 同事务。
- Artifact 写入先完成文件原子落盘，再提交数据库引用，或使用待提交状态协调。
- ToolCall 的 Idempotency Key 唯一。
- 同一 Plan Revision 唯一。
- 同一 Aggregate Sequence 唯一。

## 22. 协议演进

- 增加可选字段：兼容小版本。
- 增加枚举值：Reader 必须有 UNKNOWN 处理。
- 字段改义、删除、结构重组：提高主版本并提供转换器。
- Prompt 输出 Schema 与持久化 Schema 分离；模型输出先转换为内部对象。
- 所有历史 Fixture 进入兼容性测试。

## 23. 实现前必须补齐

进入编码阶段后，本文件需要转换为：

- Go Domain Types。
- JSON Schema 文件。
- SQLite ERD 和 Migration v1。
- OpenAPI 或 Wails Binding 类型。
- Provider/Tool/Agent 契约测试夹具。
- Event Catalog。
